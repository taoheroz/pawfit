# PawFit 🐱

แอปดูแลสุขภาพทีละนิด นับแคล โปรตีน ออกกำลังแบบไม่กดดัน พร้อมน้องแมวที่โตไปกับเธอ

## ติดตั้งบน iPhone
1. เปิดลิงก์แอปใน **Safari**
2. แตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. เปิด PawFit จากไอคอนน้องแมว

## สำหรับคนพัฒนา
```bash
npm install
npm run dev     # เปิดทดสอบในเครื่อง
npm run build   # สร้างแอปลงโฟลเดอร์ dist
```
push ขึ้น `main` แล้ว GitHub Actions จะ deploy ขึ้น GitHub Pages ให้อัตโนมัติ
รายละเอียดทั้งหมดอยู่ใน `CLAUDE.md` และ `docs/`
