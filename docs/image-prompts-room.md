# PawFit · Prompt ภาพห้องของน้อง (13 ภาพ)

## วิธีใช้
1. แนบภาพ `food_kaprao.png` จากชุดเดิมเป็นภาพอ้างอิง ทุกภาพเติมท้าย prompt ว่า `same style as the reference image`
2. ตั้งชื่อไฟล์ตามที่เขียนไว้ วางใน `assets/img/` หรือส่ง zip มาเหมือนครั้งก่อน
3. ของในห้อง (ชุดที่ 1) ขอพื้นหลังโปร่งใส (PNG) 512×512
4. ฉากห้อง (ชุดที่ 2) **ไม่ต้องโปร่งใส** ขนาดแนวนอน 3:2 และต้องเป็นห้องว่าง ไม่มีเฟอร์นิเจอร์ เพราะของที่ซื้อจะวางทับลงไป
5. ภาพไหนยังไม่มี แอปใช้ภาพวาดที่มีอยู่แทนไปก่อน
