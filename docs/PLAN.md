# PawFit — แผนงาน

ทำทีละขั้น จบแต่ละขั้นต้องเปิดดูบนมือถือได้จริงก่อนไปขั้นถัดไป

## ขั้นที่ 1: แอปจริงบน iPhone (PWA)

### 1.1 วางโครงโปรเจกต์
- สร้างโปรเจกต์ Vite + vite-plugin-pwa ตาม CLAUDE.md
- ย้าย CSS ของต้นแบบเป็นไฟล์ tokens / base / components
- **เสร็จเมื่อ:** `npm run dev` เปิดได้ เห็นแถบเมนูล่าง 5 แท็บ

### 1.2 ย้ายฟีเจอร์จากต้นแบบ (ทีละแท็บ)
ลำดับ: store + migrate → วันนี้ → อาหาร → ออกกำลัง → ร่างกาย → น้องแมว → หน้าต้อนรับ
- ใช้ข้อมูลตัวอย่างชุดเดิม (`seed()`) ไว้ทดสอบ
- **เสร็จเมื่อ:** ทุกปุ่มในต้นแบบทำงานเหมือนเดิม และเปิดแอปใหม่ข้อมูลยังอยู่

### 1.3 ทำให้ติดตั้งบน iPhone ได้
- manifest: ชื่อ PawFit, สีธีม, ไอคอน 180/192/512 (วาดหน้าน้องแมว)
- `apple-touch-icon`, `apple-mobile-web-app-capable`, status bar, safe-area
- service worker ให้เปิดแบบออฟไลน์ได้
- หน้าวิธีติดตั้ง: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **เสร็จเมื่อ:** เพิ่มไปยังหน้าจอโฮมได้ เปิดเต็มจอ ปิดเน็ตแล้วยังเปิดได้

### 1.4 Deploy
- GitHub repo ใหม่ชื่อ `pawfit` + GitHub Actions deploy ขึ้น GitHub Pages
- **เสร็จเมื่อ:** มีลิงก์ที่ส่งให้คนที่บ้านเปิดได้

### 1.5 ภาพประกอบ
- อ่านไฟล์ใน `assets/img/` → ย่อ / ตัดพื้นขาว → `public/img/` + รายการไฟล์อัตโนมัติ
- **เสร็จเมื่อ:** ภาพที่มีแสดงแทนภาพวาด ภาพที่ยังไม่มีใช้ภาพวาดเดิม

### 1.6 ดึงข้อมูลจาก Apple Health (แบบคลิปบอร์ด)
- ตาม `docs/SHORTCUTS.md` ส่วน "แบบที่ 1"
- **เสร็จเมื่อ:** กดปุ่มในแอป → คำสั่งลัดทำงาน → กลับมากดวาง → ก้าว/นอน/น้ำหนักเข้าแอปถูกวัน

### 1.7 สำรองข้อมูลให้ง่ายขึ้น
- ปุ่ม "แชร์ไฟล์สำรอง" ใช้ Web Share (ส่งเข้า LINE / Files ได้) และนำเข้าจากไฟล์
- เตือนเบา ๆ ถ้าไม่ได้สำรองเกิน 7 วัน

## ขั้นที่ 2: ใช้แล้วติด
- แจ้งเตือน (Web Push บน iOS ใช้ได้เมื่อติดตั้งลงหน้าจอโฮมแล้ว): ดื่มน้ำ, ยังไม่บันทึกมื้อเย็น, วันออกกำลัง
- ต้องมีเซิร์ฟเวอร์ส่งแจ้งเตือน → ทำพร้อมโหมดครอบครัว
- **โหมดครอบครัว** (Supabase แพ็กเกจฟรี): ล็อกอิน, กลุ่มครอบครัว, เห็น streak กัน, ภารกิจร่วม, ซิงก์ข้ามเครื่อง
- Apple Health อัตโนมัติ: คำสั่งลัดส่งข้อมูลเข้า Supabase เองทุกวัน (`docs/SHORTCUTS.md` แบบที่ 2)
- เพิ่มเมนูอาหาร, ถ่ายรูปอาหารให้ AI ประเมินแคล (ต้องมี API key ฝั่งเซิร์ฟเวอร์)

## ขั้นที่ 3: แอป iPhone เต็มรูปแบบ (ถ้าอยากได้)
- ห่อด้วย Capacitor + ปลั๊กอิน HealthKit + วิดเจ็ตหน้าจอโฮม
- ต้องมี Mac (หรือบริการ build บนคลาวด์) และ Apple Developer ประมาณ $99/ปี
- แชร์ให้ครอบครัวผ่าน TestFlight
