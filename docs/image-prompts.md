1. เจนภาพแรก (`food_kaprao.png`) ก่อน จนได้สไตล์ที่ชอบ
2. แนบภาพนั้นเป็นภาพอ้างอิงให้ภาพที่เหลือ แล้วเติมท้าย prompt ว่า `same style as the reference image`
